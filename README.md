# Mouthful

A phonetic party game for phones and tablets held in landscape. Read a string of unrelated real words out loud until it turns into a familiar phrase.

- `index.html` is the whole game in one file (the cards are built into it).
- `cards.json` holds the 230 cards (130 family, 100 18+), with `id`, `gibberish`, `answer`, `category`, `rating` and `hint`.

Play modes: Team race (2–4 teams, timed turns, scores) and Free play (no clock).
